# MindForge PWA — MVP 0.1

Первая рабочая версия мобильного тренажёра мышления.

## Что уже работает
- мобильный интерфейс, адаптированный под телефон;
- 3 задания: логика, бизнес-метрики, принятие решений;
- проверка ответа и объяснение;
- сохранение ответов в `localStorage` на текущем устройстве;
- экран прогресса и история ответов;
- экспорт прогресса в JSON;
- базовая PWA-структура и Service Worker для офлайн-кэша.

## Важно про синхронизацию
Сейчас синхронизация между устройствами **ещё не подключена**. Данные сохраняются локально на устройстве. Для синхронизации следующего этапа нужен backend с авторизацией — рекомендуемый простой вариант Supabase. Не вставляйте секретный `service_role` ключ в клиентское приложение; в браузере допустим только публичный anon/publishable key с настроенными RLS-политиками.

## Как запустить локально
PWA и Service Worker требуют `localhost` или HTTPS. Откройте терминал в папке и выполните:

```bash
python -m http.server 8000
```

На компьютере откройте `http://localhost:8000`.

Для открытия на iPhone устройство должно видеть компьютер в локальной сети, а браузер может требовать HTTPS для установки PWA. Для удобной установки лучше развернуть папку на HTTPS-хостинге (например, Netlify, Vercel или GitHub Pages).

## Установка на iPhone
1. Разверните приложение на HTTPS.
2. Откройте ссылку в Safari.
3. Нажмите «Поделиться» → «На экран Домой».
4. При желании включите «Открывать как веб-приложение».

## Ограничения MVP 0.1
- Это стартовый прототип, а не медицинский или валидированный IQ-тест.
- Анализ пока основан на правильности ответа и объяснениях, без персонального AI-разбора.
- Не удаляйте данные браузера, пока не экспортировали прогресс.
